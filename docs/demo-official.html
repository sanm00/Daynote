欢迎使用 随记

Daynote · 计划 · 执行 · 回顾 · 沉淀，一站式管理你的每一天

📅
计划
在日历上选择任意日期，添加任务、设置标签、随时改期，逾期任务可以一键移到今天。
📝
笔记
随手记录想法、会议要点、读书摘抄，支持搜索和标签筛选，输入即保存。
📊
回顾
按今天、昨天、本周、上周、当月、上月查看完成情况，用数据了解自己的节奏。
⚙️
设置
切换深浅色主题、设置默认标签，导出、导入或清空你的所有数据。
操作技巧
  • 快速添加任务 — 点计划页顶部的「+ 新建待办」展开输入框，回车即可创建
  • 给未来排计划 — 点添加行右侧的日期，或先切换到某个日期再添加
  • 任务改期 — 鼠标悬停任务行，点「改期」，一键选今天 / 明天 / 本周末 / 延后一周
  • 批量顺延 — 点面板顶部「顺延未完成」，把当天未完成的任务整体挪到第二天
  • 切换标签 — 直接点任务行上的标签，会循环切到下一个标签
  • 搜索笔记 — 使用侧边栏品牌下方的全局搜索（⌘K），标题与正文都会匹配

常见问题
数据存在哪里？会上传到服务器吗？
不会。任务和笔记只保存在当前页面内存里，主题和默认标签等偏好会存在浏览器本地。建议定期用设置页的「导出」功能做备份，避免关闭页面后丢失。
换电脑后数据怎么同步？
在旧设备上打开设置页，点「导出」得到一个 JSON 文件；在新设备的设置页点「导入」并选择该文件即可恢复。
为什么有些任务显示「已逾期」？
任务的安排日期已经过去但还没勾选完成，就会被标记为逾期。左侧「逾期未完成」卡片里可以一键把它移到今天。
任务右侧的小圆点是什么？
代表优先级。红为高、橙为中、灰为低，会根据任务标签自动分配。
如何切换成深色模式？
进入设置页，在「外观 → 主题」里选择「深色」，也可以选「跟随系统」，让界面随操作系统自动切换。
