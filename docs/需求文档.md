# 随记 Daynote 产品需求文档

## 一、产品概述

**产品名称**：随记 Daynote
**产品形态**：单文件桌面 Web 应用（原生 HTML / CSS / JS，无构建、无依赖）
**产品定位**：面向个人的轻量级日常工具，集任务计划、笔记记录、数据回顾于一体，帮助用户形成「计划 → 执行 → 回顾 → 沉淀」的日常闭环。
**目标用户**：需要管理每日待办、记录灵感与笔记、并希望定期回顾节奏的个人用户。
**核心价值**：无账号、无网络依赖，操作即时反馈，界面简洁现代，支持本地导出备份。

---

## 二、整体布局

应用采用经典桌面三栏布局：

- **左侧导航栏**
  - 品牌标识（羽毛笔 logo + 「随记 Daynote」）。
  - 导航项：计划、笔记、回顾、设置、帮助。
  - **今日进度卡片**：环形进度显示今日完成百分比、「N / M 件待办已完成」、底部随状态轮换的鼓励语（未开始 / 进行中 / 全部完成三种文案）。
  - **金句卡片**：轮播励志短句，多行轮播圆点，鼠标悬停暂停。
- **顶部标题栏**：应用名称、全局搜索入口（`⌘K` / `Ctrl+K`）、窗口控制。
- **主内容区**：根据导航切换对应页面；搜索为独立覆盖页。

标签体系贯穿全应用，固定四类：**工作 / 学习 / 生活 / 健康**，各有专属配色（浅/深主题分别适配）。

## 三、功能模块

### 3.1 计划

**月历视图**
- 展示当前月份日历，支持上月 / 下月切换。
- 每周从周一开始（一…日）。
- 每个日期下方用圆点标记任务状态：绿色 = 有已完成，橙色 = 有未完成。任务若排期跨天，则其区间覆盖的每一天都参与标记。
- 今天高亮、选中日期有选中态；点击任意日期切换查看该日任务。
- 底部图例说明圆点含义。

**多种任务视图**（左侧入口切换，主面板随之变化）
- **日期视图**（默认）：显示选中日期覆盖的任务（排期区间包含该日即出现），按「待完成 / 已完成」分组，顶部有当天进度条。
- **逾期视图**：入口为左侧「逾期」计数卡；列出结束日（截止日）已过但未完成的任务，副标题显示最早逾期日，提供「全部移到今天」批量操作。
- **待排期视图**：入口为左侧「待排期」计数卡；收集尚未安排日子的想法（来自快速添加或笔记解析），提供「全部排到今天」。
- **全部待处理视图**：入口为左侧「全部待处理」卡；聚合所有未完成任务，按「逾期 / 今天 / 未来 / 待排期」分段，副标题汇总数量。
- 三个计数卡实时反映数量，为零时置灰。

**任务行信息**
- 标题、标签（可点）、优先级圆点（红 = 高、橙 = 中、灰 = 低）、排期文案（单日显示「今天 / 明天 / 逾期 · M月D日」，跨天显示「M月D日–M月D日」并附「跨天」小标）、完成时刻（已完成时显示「完成于 今天 HH:MM」，非当天则显示「完成于 YYYY-MM-DD HH:MM」）。
- 来源标记：待排期任务区分「来自笔记」等来源。
- 已完成任务划线弱化。

**快速添加**
- 「+ 新建待办」展开内联表单：多行输入框 + 标签下拉 + 日期区间选择 + 添加按钮。
- 回车提交、`Shift + 回车`换行、`Esc`取消并收起。
- 未选日期则进入「待排期」，选定日期（可为跨天区间）则直接排期并 toast 提示。
- 提交后输入框保持聚焦，便于连续录入。

**任务操作**
- **勾选完成 / 取消完成**：点击复选框，完成时写入完整完成时间戳，取消时清空。带勾选动画。
- **改期**：悬停出现「改期 / 排期」按钮，展开快捷选项（今天、明天、本周末、延后一周）与「选择日期」弹出日历（支持先点开始日、再点结束日排成一段）；也可移回待排期。
- **切换标签**：直接点击任务上的标签循环切换四种标签。
- **删除**：悬停出现删除按钮。

**日期弹出选择器（date-pop）**
- 浮动月历，支持翻月，底部预设：今天 / 明天 / 待排期（清空）。
- **区间选择**：先点一天作为开始日，再点另一天作为结束日即可排成一整段；两点相同即为单日。悬停时预览区间，底部提示当前选择。
- 跟随触发元素定位，窗口尺寸变化时重新定位。

**批量与导航**
- **顺延未完成**：把结束日（截止日）为当前查看日期的未完成任务整体后移一天，保持原有跨度不变。
- 日期导航：前一天 / 后一天 / 「今天」快捷按钮；切换日期时快速添加的默认日期同步更新。

**空状态**
- 各视图无数据时给出图标 + 主文案 + 副文案（如未来日「留出一点空间，让那天自己长出来」）。

### 3.2 笔记

**笔记列表（左栏）**
- 按更新时间倒序。
- 每条显示标题、内容摘要（纯文本前若干字）、标签、相对更新时间（刚刚 / N 分钟前 / 今天 HH:MM / X 天前 …）。
- 当前选中笔记高亮。

**搜索与筛选**
- 顶部搜索框：按标题或正文关键词实时过滤。
- 标签筛选 chips：全部 / 工作 / 学习 / 生活 / 健康（无边框胶囊样式，选中态加重）。

**新建笔记**
- 「+ 新建笔记」创建空白笔记，默认标签取自设置中的默认标签；自动选中并聚焦标题。

**编辑器（右栏）**
- 标题输入框、标签切换 chips、内容区。
- **预览 / 编辑双模式**切换（分段开关）：预览渲染 Markdown，编辑显示源码文本域。
- 所有修改实时保存，列表摘要与「更新于 …」时间同步更新。
- 删除按钮：删除后自动选中下一条；列表为空显示空状态。

**Markdown 支持**
- 标题（`#`~`######`，最深四级）、粗体 / 斜体 / 删除线、行内代码、代码块（可带语言标注）、引用块、有序 / 无序列表、**任务清单**（`- [ ]` / `- [x]` 渲染为可勾样式的行内待办）、分隔线、链接、图片、段落换行。
- 提供 `plainText` 抽取纯文本，用于摘要与搜索匹配。
- 空内容有引导占位。

### 3.3 回顾

**时间范围切换**
- 标签页：今天、昨天、本周、上周、当月、上月。
- 顶部显示当前范围的日期区间。

**统计卡片（5 张）**
口径统一如下（周期归属一律以任务的**结束日/截止日** `endDate` 为准）：
- **完成任务**：完成日期（`doneAt`）落在所选周期内的任务数；副标题显示周期内安排总数及待排期数。
- **完成率**：分母 = 结束日落在周期内的任务数，分子 = 其中已完成数；环形进度 + 百分比；副标题显示与上一等长周期的对比趋势（较上一周期 ±X%，正绿负红），无历史数据时退化为「N 项未完成」。
- **逾期任务**：结束日落在周期内且（逾期未完成 或 迟于结束日才完成）的任务数；副标题拆分「逾期完成 X · 未完成 Y」；非零时红色警示。
- **有产出的天数**：周期内至少完成一项任务的天数（按完成日期去重）；副标题显示区间总天数。
- **新增笔记**：`createdAt` 落在周期内的笔记数；副标题显示「另编辑 N 篇过往笔记」（创建于更早但在本周期被更新、且不重复计新增）。

**每日完成情况图表**
- **最小展示粒度为一周**：当选择单日（今天 / 昨天）时，图表补足所在自然周（周一至周日），并在标题下以副标题标明「所在周 · 起止日期」，消除 tab 与图表口径错位。
- **所选日高亮**：仅单日场景对所选日做柔和列底高亮 + 主色加粗；「今天」始终单独标记；周末列标签弱化。多日区间不出现单日高亮。
- **柱状图 / 折线图可切换**（右上角分段开关）：
  - 折线图按容器实际尺寸绘制，铺满卡片；含面积填充、数据点、数值标签、上下基线，所选日附竖向虚线指引。
  - 切换状态跨时间范围记忆，不因切 tab 重置。
- **自定义 hover tooltip**：柱与折线数据点均跟随鼠标显示「M月D日 星期X · 完成 N 项」（折线用透明大热区提升命中）。
- 密集区间（月）自动抽样显示横轴标签。

**标签分布**
- 按已完成任务的标签统计数量，横向条形展示相对占比。

**完成记录**
- 按**完成日期**分组倒序列出已完成任务，显示标题、标签、排期文案、完成时刻；每组显示条目数。
- **剩余未完成**：列出结束日落在周期内且未完成的任务，**不按日期分组**（平铺，逾期在前），每条显示排期文案，逾期项标注「已逾期」；点击可定位到计划页。
- 仅展示待办，不与笔记混排，避免歧义。

**空状态**
- 各区块无数据时给出对应提示。

### 3.4 全局搜索

- 入口：顶部搜索按钮或 `⌘K` / `Ctrl+K`；`Esc` 返回来源页。
- 一次搜遍笔记与待办；类型 tabs：全部 / 笔记 / 待办。
- 结果分组显示，命中关键词高亮，笔记显示上下文摘要与更新时间、待办显示状态与日期（逾期标红）。
- 顶部汇总命中总数（笔记 / 待办分项）；空输入给搜索建议，无结果给引导文案。
- 点击结果跳转到对应笔记或定位到计划页相应日期 / 待排期，并 toast 提示。

### 3.5 设置

**外观**
- 主题：浅色 / 深色 / 跟随系统；切换立即生效并保存到浏览器本地。

**任务偏好**
- 默认标签：新建任务与新建笔记默认选中标签。

**数据管理**
- **导出数据**：任务、笔记、设置导出为 JSON 文件。
- **导入数据**：选择 JSON 文件恢复，覆盖当前全部内容。
- **清空所有数据**：二次确认后清空全部任务与笔记。

**关于**
- 应用名称（随记）、英文名（Daynote）、版本、数据存储位置、技术栈。

## 四、数据与存储

- **任务模型**：`{ id, title, tag, prio(high/mid/low), beginDate(开始日 YYYY-MM-DD 或 null=待排期), endDate(结束日 YYYY-MM-DD 或 null=待排期), done(bool), doneAt(完成时间戳 ISO 或 null), source, parsedAt }`。
  - 不变量：待排期时 `beginDate === null && endDate === null`；单日 `beginDate === endDate`；跨天 `beginDate <= endDate`。导入时按此归一化。
  - `doneAt` 记录**完整完成时刻**，回顾页据此判定「周期内完成」「逾期完成」；**周期归属与逾期判定均以 `endDate` 为准**。
- **笔记模型**：`{ id, title, content(Markdown), tag, createdAt, updatedAt }`。
- **持久化**：桌面端由 Tauri 后端把数据写入本地文件系统，**默认存储根 `~/.daynote`**；**开发（debug）构建单独存储到 `src-tauri/data/` 目录**，避免污染用户家目录。
  - 目录结构：`state.json`（设置 + schema 版本）、`tasks.json`、`notes.json`、`backups/<时间戳>/`（每次写入前的备份，最多保留 20 份）。
  - 写入采用「临时文件 + 原子 rename」，内容未变化时跳过写入与备份。
  - 浏览器（`npm run dev` 无 Tauri 外壳时）回退到 `localStorage`，仅用于开发预览。
- **备份迁移**：通过设置页「导出 / 导入」JSON 实现跨设备迁移。
- **隐私**：数据仅存本地，不上传服务器。
