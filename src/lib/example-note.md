# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题（显示为四级样式）

###### 六级标题（显示为四级样式）

## 段落与换行

空一行开始新段落。

同一段中直接换行，
预览时也会保留换行。

## 文字格式

用 **两个星号** 或 __两个下划线__ 表示粗体。

用 *一个星号* 或 _一个下划线_ 表示斜体。

用 ~~删除线~~ 标记不再需要的内容。

用 `行内代码` 标记命令、变量或语法，例如 `**粗体**`。

## 无序列表

- 用短横线开始一项
- 下一项可以包含 **粗体** 和 `代码`

* 也可以使用星号
* 每项单独占一行

+ 也可以使用加号
+ 保持相同写法更便于阅读

## 有序列表

1. 记录想法
2. 安排待办
3. 回顾进展

## 待办列表

- [ ] 一项未完成的笔记内待办
- [x] 一项已完成的笔记内待办

笔记内的勾选项用于展示清单，与计划页的待办分开保存。

## 引用

> 把重要的事记下来。
> 引用也可以包含 **粗体**、*斜体* 和 `行内代码`。

## 分隔线

三个短横线、星号或下划线均可生成分隔线：

---

***

___

## 链接与图片

链接格式为 `[文字](地址)`，例如：[Markdown 语法说明](https://daringfireball.net/projects/markdown/syntax)。

图片格式为 `![说明](图片地址)`。下面使用应用内置图标，无需联网即可查看：

![Daynote 应用图标]({{icon}})

## 表格

表头下一行使用短横线分隔，冒号可以指定左对齐、居中和右对齐。

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| **计划** | 今天 | 1 |
| 笔记 | `Markdown` | 2 |
| 分隔符示例 | 内容中的竖线：\| | 3 |

## 代码块

用三个反引号包围代码，并在开头指定语言以启用语法高亮：

```typescript
const message = '你好，随记';
function greet(name: string) {
  return `${message}，${name}`;
}
console.log(greet('新的一天'));
```

也可以省略语言，记录纯文本：

```
今天：完成一件重要的事
明天：继续推进跨天计划
```

可以自由修改或删除这篇示例笔记，开始记录自己的内容。
